# Five-minute offline presentation

Before presenting, install the verified APK, open it once as a practical device check, then enable airplane mode. Bundled content does not require an initial download. The green **OFFLINE SHOWCASE · DEMO MODE** strip identifies the entire demonstration.

1. **0:00–1:00:** Show the approved logo, tagline, editorial home and featured collections. Explain the multi-brand marketplace proposition.
2. **1:00–2:00:** Open Brands and a fictional storefront. Mehr Atelier, Gul Studio and Saanjh Objects are demonstration names, not partners or endorsements.
3. **2:00–3:00:** Explore categories and search “rose”. Open a product, show PKR pricing and select a demo option. Photographs are AI illustrations, not supplier listings.
4. **3:00–4:00:** Add items across labels to the demo bag. Change quantities or remove an item. Continue to demo checkout using the fixed illustrative address.
5. **4:00–5:00:** Review and confirm the simulated order. Point out the explicit “no purchase” confirmation. Close and reopen the app to demonstrate offline availability.

Only the showcase is simulated. Existing live shopping adapters support accounts, real backend catalogue/cart/addresses, COD and order history, with server authorization and idempotency. This candidate does **not** establish operational online shopping. Shop live reports the unavailable deployment clearly; never present that as a live order demonstration.

Before commercial launch: approved hosting/TLS/database and backups; real catalogue/image pipeline and permission to publish brands; merchant onboarding and fulfillment operators; security exception resolution/decision; production signing and current physical-device/live checkout acceptance.
